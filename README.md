# عبدالرحمن سليمان — منصة مسار (Masar)

موقع ثابت (HTML + Tailwind CDN) مبني من تصاميم Stitch، بالهوية البصرية "Sovereign Executive" (راجع `assets/DESIGN.md`). افتح `index.html` مباشرة أو شغّل `python3 -m http.server`.

| المرحلة (رحلة المستخدم) | الصفحات |
|---|---|
| 1 الاكتشاف والتسويق | `index.html` · `store.html` · `knowledge.html` · `article.html` · `about.html` |
| 2 الاستحواذ والتجارة | `product.html` · `checkout.html` · `success.html` |
| 3 التسجيل والمطابقة | `login.html` · `onboarding.html` |
| 4 جناح المستثمرين والمؤسسين | `dashboard.html` · `kpi.html` · `copilot.html` |
| 5 الإدارة التنفيذية | `admin.html` · `admin-products.html` · `admin-users.html` |
| مرجعية | `brand.html` · `journey.html` · `legal.html` |

`assets/site.js`: سلة مشتريات (localStorage)، تدفق الشراء والدخول، ورسائل تأكيد. الصور تُحمَّل من روابط Stitch الأصلية.
